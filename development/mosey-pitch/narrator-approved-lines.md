# Narrator Approved Lines — inventory

The banked, Natan-approved line inventory. Every line here was either accepted as-written ("yes") or is Natan's own "other" rewrite (his rewrite is canonical). Companion to the R&D log at [narrator-line-lab.md](narrator-line-lab.md).

**Purpose:** a growing bank of usable narrator lines, tagged so they can later be spawned at the correct in-app moment (the trigger category) and balanced by comedic shape (the engine). This is the product; the lab is the workshop.

**Maintenance rule:** after each rating round, append every new "yes" and every "other" rewrite here with an ID, verbatim. Never edit an approved line's wording (it's Natan's). Retag freely.

## Trigger categories (provisional — for spawn timing)
- `getting-out` — pre-walk: at the door, keys / leash / shoes / coat. The hardest step; the app's emotional core.
- `on-walk` — outside, found objects, places (Good Bench, Tree)
- `mailbox` — the daily micro-walk: the red-flagged Mailbox, mail, Pigeon delivery
- `weather` — rain, sun, gray, warm, the Puddle
- `resident` — Squirrel, Crow, Snail, Cat, Spider, Tortoise (see sub-tag)
- `home-idle` — napping, guarding, sunbeam, window, mealtime
- `user-interaction` — reactions to what the user does: petting, scratching, treats, sighs, gifts
- `mischief` — dug a hole, rolled in something, the vacuum
- `sincere` — milestone / quiet fondness
- `post-walk` — summary / field-report tone

## Engines (comedic shape)
- `joy-cue` — flat narrator claim + a physical animation cue in `[brackets]` that contradicts/oversells it
- `verbal-wit` — two-beat setup → wit or funny truth, routed through Mosey's POV where possible
- `parallel` — "You [verb]. Mosey [verb]." mirroring
- `afterthought` — a `[beat]` then a reconsidering addition
- `strikethrough` — `~~struck~~` overreach, strike and stop
- `sincerity` — plain, short, about Mosey's own state
- `escalation` — earned multi-beat build landing on a real tag

## ★ The payoff rule (from R14 — the clearest bar we have)
Land every payoff CONCRETELY, in one of three places: **(A) object → implied real-world fact** ("a wristwatch. It is set to another time zone."), **(B) animation showing disproportionate joy / contrast** ("a parking fine. [Mosey dancing with it]"), or **(C) mock-operation with labeled steps + animation** ("Operation excavate: engaged. Step one: heavy breathing."). If the last clause is the narrator being clever *about* the moment, cut it. ("dramatic-irony" text lines re-tagged under object-implication where the object carries it.)

## Device added R13
- `precarious-pose` — state Mosey's aspirational cool/resolve, then name the SPECIFIC tiny thing that would shatter it ("A biscuit would ruin everything"). Consequence implied, never shown. Hinges on a concrete specific detail.

## The bar (from repeated near-wipeouts R8 & R13)
Every line must be a DISTINCT idea (never paired/systematized), anchored to a SPECIFIC concrete detail, meaning IMPLIED not stated, dry, text-first. Abstract or explained = rejected. Specificity is the whole game.

## Character-mode map (which register each resident wants — see lab for evidence)
- **Cat** → Mosey imitating the Cat's cool and failing (the tail betrays). · **Crow** → Mosey proudly displaying obviously-stolen loot. · **Squirrel** → paranoid dog-logic verbalized, or crisp war-drama. · **Snail** → Mosey's impatience with the slowness. · **Pigeon** → terse text irony about misplaced certainty. · **Mosey solo** → dry disproportionate drama, never sweet.

## Device added R11
- `text-points-at-animation` — the narrator gestures directly at the drawing ("Like this.") so text and animation interlock. Half the joke (or more) lives in the bracket; build lines animation-first.

★ = Natan-authored (canonical reference lines — the truest voice samples in the bank).

## Engine added R9
- `dramatic-irony` — state facts that reveal a reality a character MISUNDERSTANDS (Mosey misreads a snub as honor, a reflection as a friend; the Crow's theft as a gift; the Pigeon/Squirrel oblivious). Report deadpan and STOP — never name the theme; the reader reads between the lines. This is now the deepest, highest-value engine (see Principle #4 in the lab). Pairs with the character-theme map.

## Engines added since v1
- `mock-serious` — a COMMITTED serious frame (military, detective) that ESCALATES over beats, each adding vivid/gross physical comedy. Distinct from dead officialese (which is one lazy bureaucratic tag). L039, L042.
- `fragment-for-timing` — lead with the abstract claim, reveal the mundane/gross cause as a fragment after the period. L037, L040.
- `attributed-belief` — state a self-serving fact, tag "...According to Mosey." ⚠ UNRELIABLE (1-for-3 in testing) — keep L035 but don't lean on it.
- `dog-world lens` — widen from Mosey to "canines"/"owners". ⚠ UNRELIABLE (1-for-2) — occasional at best. L032.
